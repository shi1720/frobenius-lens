# Literature search and positioning

Search date: 17 October 2026. This is a bounded, reproducible search log, not a systematic-review claim.

## Questions and search phrases

1. Is finite periodic CA algebra new? Search: `Algebraic properties of cellular automata Martin Odlyzko Wolfram`; `cellular automata finite fields Frobenius`.
2. Is CA rule identification new? Search: `linear cellular automata identifiability`; `cellular automata identification polynomial rule observation`; `Fast rule identification and neighborhood selection`.
3. Has temporal sampling been studied? Search: `cellular automata identification subsampling`; `cellular automata stroboscopic`; `system aliasing identifiability`.
4. Does repeated-root coding theory already contain the algebra? Search: `Repeated-root cyclic codes Castagnoli Massey Schoeller von Seemann`.
5. What is the connection to evaluators for generated mathematical code? Search: `FunSearch mathematical discoveries program search`; `AlphaEvolve scientific algorithmic discovery`; `Effective Harness Engineering Algorithm Discovery`.
6. Which existing products could host a diagnostic? Read official Golly, SageMath, and Wolfram CellularAutomaton documentation.

## Topic selection

Broad topics rejected: “LLMs discover CA rules,” “finite rings create artifacts,” and “polynomial certificates are new.” These collide with substantial established work or require unperformed model experiments. The selected problem narrows the object to known-seed, full-observation, Frobenius-time experiment suites and returns a complete ambiguity space, not just an example of a misleading picture.

The author's supplied research portfolio was screened locally through extracted titles/abstracts and full-text keyword searches. No paper in that portfolio concerned this cellular-automaton experiment-design problem. Private portfolio documents are not redistributed with the public artifact.

## Remaining uncertainty

Search cannot establish universal absence of equivalent results, especially across older algebraic CA, coding theory, or system-identification terminology. The manuscript explicitly credits the mathematical ingredients and confines the novelty claim to the audit/repair formulation and artifact. The exact guarantees and experiments stand independently of a strong priority claim.
