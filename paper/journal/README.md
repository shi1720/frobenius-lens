# Journal manuscript version

Submitted for consideration to the **Journal of Cellular Automata** on 17 October 2026 through its published editor email route. Editorial acknowledgment and a manuscript reference are pending; no acceptance is claimed. This is the same research as the original preprint, adapted to the publisher layout, with an expanded bibliography, ORCID, and nomenclature.

- `Frobenius_Lens_JCA_Submission.pdf`: submitted manuscript.
- `main.tex`, `references.bib`: journal manuscript sources.
- The underlying research code and results remain those of software release v0.1.0.

The official publisher class and bibliography style are available in [the publisher TeX guide](https://www.oldcitypublishing.com/wp-content/uploads/2013/09/TEX-Style-Guide.zip). The submitted source package uses its `ijuc.cls` and `ijuc.bst`, changing the bibliography style to preserve citation order and setting the documented 152 x 228 mm trim and 108 x 180 mm text area. These publisher-supplied style files are not relicensed or redistributed here.

To reproduce the journal PDF, put the downloaded class and a citation-order copy of the bibliography style in this directory as `ijuc.cls` and `ijuc-unsorted.bst`; change the class bibliography-style call to the latter. The figure paths point to the repository's existing `figures/` directory. Compile `main.tex` with Tectonic or a modern TeX distribution.

The complete TeX and vector-figure package was supplied directly to the editor with the PDF. Private correspondence and personal postal contact details are excluded from the public repository.
